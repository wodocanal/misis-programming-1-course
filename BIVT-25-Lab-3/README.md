# Лабораторная работа №3

Алгоритмические задачи с циклами. Учебная работа на C# из сборника по программированию, алгоритмизации и основам ООП.

## Состав

- `Lab3/` — исходный код и файл решения `Lab3.sln`.
- `Lab3test/` — исходные тесты MSTest и, где предусмотрено, тестовые данные.


Варианты заданий и степень их реализации сохранены из исходного репозитория: среди файлов могут быть шаблоны и незавершённые варианты.

## Сборка и тесты

Команды выполняются из этой папки. Нужны .NET SDK 8 и среда выполнения .NET 8; при первом запуске требуется восстановление пакетов NuGet.

```bash
dotnet build Lab3/Lab3.csproj
dotnet test Lab3test/Lab3test.csproj
```

Перенос не включает проверку работоспособности исходных решений и прохождения всех тестов.
