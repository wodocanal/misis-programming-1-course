# Лабораторная работа №9

Обработка текста и иерархии классов. Учебная работа на C# из сборника по программированию, алгоритмизации и основам ООП.

## Состав

- `Lab9/` — исходный код и файл решения `Lab9.sln`.
- `Lab9Test/` — исходные тесты MSTest и, где предусмотрено, тестовые данные.


Варианты заданий и степень их реализации сохранены из исходного репозитория: среди файлов могут быть шаблоны и незавершённые варианты.

## Сборка и тесты

Команды выполняются из этой папки. Нужны .NET SDK 8 и 9; при первом запуске требуется восстановление пакетов NuGet.

```bash
dotnet build Lab9/Lab9.csproj
dotnet test Lab9Test/Lab9Test.csproj
```

Перенос не включает проверку работоспособности исходных решений и прохождения всех тестов.
