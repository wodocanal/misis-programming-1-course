# Лабораторная работа №10

Файлы и сериализация. Учебная работа на C# из сборника по программированию, алгоритмизации и основам ООП.

## Состав

- `Lab10/` — исходный код и файл решения `Lab10.sln`.
- `Lab10Test/` — исходные тесты MSTest и, где предусмотрено, тестовые данные.

- `Lab9/` — зависимый проект из исходного репозитория лабораторной №10; это отдельная сохранённая версия, необходимая для исходных ссылок между проектами.

Варианты заданий и степень их реализации сохранены из исходного репозитория: среди файлов могут быть шаблоны и незавершённые варианты.

## Сборка и тесты

Команды выполняются из этой папки. Нужны .NET SDK 8 и 9; при первом запуске требуется восстановление пакетов NuGet.

```bash
dotnet build Lab10/Lab10.csproj
dotnet test Lab10Test/Lab10Test.csproj
```

Перенос не включает проверку работоспособности исходных решений и прохождения всех тестов.
