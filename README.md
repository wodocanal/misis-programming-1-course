## Финальный проект — MISIS Chess OOP

[Описание и инструкции](chess-misis-oop/README.MD) · [Исходный код](chess-misis-oop/chess/)

Настольные шахматы для двух игроков на C# и Avalonia UI, с сохранением и загрузкой партий в JSON/XML. Пользовательский интерфейс и модель игры разделены на проекты.

**Совместная работа [wodocanal](https://github.com/wodocanal) и [KiraFlux](https://github.com/KiraFlux).** Участники подтверждены историей вкладов исходного репозитория.

## Как работать со сборником

Нужны .NET SDK 8 и 9 и соответствующие среды выполнения: лабораторные ориентированы на .NET 8, тесты №9–10 — на .NET 9, шахматное приложение — на .NET 9, его модель — на .NET 8. При первой сборке требуется доступ к NuGet.

Сборка и тестирование отдельной лабораторной из корня сборника, на примере №1:

```bash
dotnet build BIVT-25-Lab-1/Lab1/Lab1.csproj
dotnet test BIVT-25-Lab-1/Lab1test/Lab1test.csproj
```

Точные пути для остальных работ указаны в их README. Запуск шахмат из корня:

```bash
dotnet run --project chess-misis-oop/chess/Chess/Chess.csproj
```

Проекты сохранены в учебном состоянии. В репозиториях присутствуют как реализации, так и шаблонные или незавершённые варианты; перенос сам по себе не означает успешного прохождения всех тестов. Общего решения `.sln` для всех работ нет — каждая работа собирается отдельно.

## О переносе

- Все 11 исходных репозиториев представлены обычными папками, без вложенных `.git` и подмодулей.
- Исходный код, тесты, задания и лицензия сохранены. Исключены служебные каталоги `.git`, `bin`, `obj`, `.idea`, `.vs` и файлы `.DS_Store`.
- История коммитов исходных репозиториев не объединялась; URL, ветки и точные коммиты зафиксированы в [IMPORTS.json](IMPORTS.json).
- В лабораторной №10 сохранён её собственный проект `Lab9`, на который ссылается исходное решение.
- Исходные файлы GitHub Actions сохранены внутри папок работ. В таком расположении они не запускаются как CI общего репозитория.
